# Contributing

## Licence of contributions

Read the component mapping in [LICENSE](LICENSE) before contributing:

- Client, shared code and other original tools/documentation: MIT.
- Server, server Windows Forms application and tests: GPL-3.0-only.
- Material carrying an explicit third-party notice retains its existing terms.

By submitting a new contribution for inclusion, you agree to license your
original contribution under the licence applicable to its component. You retain
your copyright. Submit only material you have permission to contribute under
those terms, and identify any third-party material and its licence explicitly.

Do not copy GPL-only server code into MIT components. Shared code needed by
both client and server belongs under MIT only when its copyright holders have
authorized that licence. Moving existing code does not change its licence.

This policy applies to new submissions; it does not retroactively obtain
permission to relicense earlier contributions or assign copyright.
